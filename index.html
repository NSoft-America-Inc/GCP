Google's Infrastructure

Backbone
Global, meshed backbone network to interconnect data centers and deliver traffic to their Edge Points of Presence (POPs).
PoPs
70+ edge PoPs in 33 countries interconnected via the Backbone network.
Edge Caching
A caching platform that sits on top of the infrastructure network. Edge locations can be found in virtually every country.
Regions
Specific geographical locations where you can run your resources. Collection of zones. Regional resources are available to resources in any zone in the region. Example: us-central1
Multi-Regions
A multi-regional location is a general geographical area (e.g. United States). Multi-region locations contain multiple regional locations, each separated by at least 100 miles.
Zones
Isolated locations within a region. Zonal resources are only available in that zone. Example: us-central1-a

GCP Networking Fundamentals

VPC Networks – Pricing
Sub-hour billing (billed in minutes). Ingress is free; Egress is charged. Egress to some GCP services is sometimes free.
Sustained-Use Discounts
Applied automatically — no action required. You can get up to 30% net discount for instances that run the entire month. No upfront costs and not tied to machine type.
Committed-Use Discounts
Similar to AWS Reserved Instances.
Security
All data is encrypted at rest. All WAN traffic is encrypted automatically. Google's BeyondCorp model shifts access controls from the network perimeter to individual devices and users — allowing employees to work securely from any location without a VPN.

Cloud IAM

Overview
Provides granular access to resources and enforces the principle of least privilege.
Members (Who)
Person (Google Account), Google Group, Service Account — identified by @developer.gserviceaccount.com
Permissions & Roles (What)
Role: Collection of permissions to use/manage GCP resources, assigned to users. Permissions: Give access to a given resource, identified by .. (e.g. pubsub.subscriptions.consume).
Policies
Bind Members to Roles at a hierarchy level (Organisation, Folder, Project, or Resource). Hierarchically defined — parent overrules child policy.
Service Accounts
Global. Similar to AWS Role. Special type of Google account representing an application, not an end user. Can be assumed by applications or individual users when authorised.
GCP-Managed Keys
Used by GCP services such as App Engine and Compute Engine. Keys cannot be downloaded. Rotated automatically on a weekly basis.
User-Managed Keys
Created, downloadable, and managed by users. Expire 10 years from creation.
Primitive Roles
Historical roles before Cloud IAM. Applied at the Project level (broad scope). Types: Viewer (Read only), Editor (Read + Write), Owner (Read + Write + manage access + billing).
Predefined Roles
Much more granular access, applied at the Resource level.
Cloud Identity
Identity as a Service (IDaaS). Supports MFA, SSO via OIDC/SAML/OAuth2. Can sync from AD and LDAP via Google Cloud Directory Sync.

Resource Management

Cloud Resource Manager
Hierarchically manage resources by project, folder, and organisation. Organisation is the root node. Provides a Recycle Bin to undelete projects. Custom IAM roles can be defined at the organisation level.
Cloud Audit Logging
Global. Who did what, where, and when? Two audit logs per project/organisation: Admin Activity (400-day free retention), Data Access (7-day free; 30-day paid).
Cloud KMS
Regional and Global. Low-latency service to manage AES256 encryption keys. Rotate keys automatically or on demand. Key deletion has 24-hour delay. Pay for active key versions stored and key use operations.
Cloud IAP
Guards apps running on GCP through identity verification instead of VPN access. Based on CLB and IAM — only passes authorised requests.
Security Scanner
Global. Free (limited) GAE vulnerability scanner with very low false positive rates. Crawler-based. Detects: XSS, Flash injection, Mixed content, Outdated/insecure libraries.

Compute Options

GCE (Google Compute Engine)
Zonal. IaaS. VMs referred to as Instances. Full control and flexibility over: CPU/GPU, Memory, Disk Space, OS, Firewall Controls, Network Connection/Management (VPN/Load Balancing).
Instance Groups – Managed
Uses instance templates to create a group of identical resources. Benefits: Automatic scaling, load-balanced traffic distribution, automatic instance recreation on failure.
Managed – Zonal
Contains instances from the same zone. Choose if you want to avoid cross-zone latency or need fine-grained control of group sizes.
Managed – Regional
Contains instances from multiple zones across the region. Generally recommended — protects against zonal failures.
Instance Groups – Unmanaged
Groups of dissimilar instances. No autoscaling, rolling updates, or instance templates. Use for pre-existing configurations or dissimilar instances needing load balancing.
GKE (Google Kubernetes Engine)
Regional. Manages applications, not machines. Powered by Kubernetes. Deploy containerised applications. No IAM integration — manage secrets manually for other GCP services. Production clusters require ≥3 nodes.
App Engine – Standard
Regional. Zero-admin managed service. Supports: Python, Java, Go, PHP. Scales to zero.
App Engine – Flexible
Docker-based. Supports: Java 8, Python 2.7/3.5, Node.js, Ruby, PHP, .NET Core, Go, and any custom Docker runtime.
Cloud Functions
Regional. FaaS (Serverless). Runs Node.js code in response to events (GCS, Pub/Sub, HTTP). Pay for CPU & RAM per 100ms. Massively horizontally scalable.

Storage, DB & Transfer

Local SSD
Zonal. Data encrypted at rest. 375GB SSD attached to each server. Data lost on instance shutdown (survives live migration). Pay for GB-month provisioned.
Persistent Disk
Zonal. Performance scales with volume size (below Local SSD speed). Resizable while in use (requires filesystem update in VM). Max file size: 10TB.
Snapshots
Global. Snapshot Persistent Disks to create machine images. Similar to AWS EBS snapshots.
Cloud SQL
Regional. Fully Managed. Supports MySQL and PostgreSQL. Automatic replication, backup, and failover. Scaling is manual (vertical and horizontal).
Cloud Spanner
Regional / Multi-Regional / Global. Horizontally scalable. Strongly consistent (external consistency). Relational structure with non-relational horizontal scale. Supports SQL, ACID transactions. Scales from 1 to thousands of nodes; requires 3 nodes for production. Pay for provisioned node time and storage.
BigQuery
Multi-Regional. Serverless, column-store data warehouse. Supports SQL. Pay for GBs scanned per query (cached results free), GB-months stored, and streaming inserts per GB.
Cloud Datastore
Regional / Multi-Regional. Fully Managed NoSQL DB. Similar to DynamoDB. Supports ACID transactions, SQL-like queries, Indexes, RESTful interface. Pay for GB-months storage and IO operations.
Bigtable
Regional. Fully Managed. Low latency, high throughput NoSQL DB. Used for large operational/analytical workloads. Supports HBase API. Integrates with Hadoop, Dataflow, Dataproc. Use when: storing 1TB+ structured data, very high write volume, single-digit ms latency requirements, or migrating from HBase.
Cloud Storage
Regional / Multi-Regional. Fully Managed. Strongly consistent for overwrite PUTs and DELETEs. Durability: 11 nines. Supports site hosting and lifecycle features.
Data Transfer Appliance
Rackable, high-capacity storage server. Physically ship data to GCS. Similar to AWS Snowball. Ingest only. 100TB or 480TB versions.
Storage Transfer Service
Global. Transfer data from S3, HTTP/HTTPS endpoints, or GCS buckets to a GCS bucket. Pay for data transfer actions.

Networking

Google Domains
Global. Google's domain registrar. Built-in DNS or custom nameservers. Supports DNSSEC.
Cloud DNS
Global. 100% uptime guarantee. Low latency globally. Supports DNSSEC. Pay for hosted zones (fixed fee) and DNS lookups.
Static IP
Regional & Global. Regional Static IP for GCE instances and Network LBs. Global Static IP (Anycast) for Global Load Balancers (HTTP(S), SSL Proxy, TCP Proxy). Pay for IPs not in use.
Cloud Load Balancing
Regional & Global. Built into SDN — handles spikes without prewarming. Regional Network LB: Session Affinity, forwarding rules by IP/protocol/port, Round Robin, Health Checks. Global LB: Multi-region failover for HTTP(S), SSL Proxy, TCP Proxy. Types: HTTP(S) LB, TCP LB, SSL Proxy, TCP Proxy, UDP LB.
Cloud CDN
Global. Low-latency content delivery. Based on HTTP(S) CLB. Integrated with GCE and GCS. Supports GCP only (HTTP(S) LBs). Backend can be a GCS Bucket. Supports HTTP/2 and HTTPS. Pay for: POP-to-client network egress, HTTP(S) request volume, per cache invalidation request.
VPC
Global. Global IPv4 unicast SDN for GCP resources. Subnets are Regional. Can be shared across projects or peered with other VPCs. Can enable private access to GCP services (e.g. BigQuery, GCS). Pay for certain services (e.g. VPN) and network egress.
Cloud Interconnect
Regional / Multi-Regional. Connects external networks to Google's network. Private Connections (RFC1918 IPs, with SLA): Dedicated Interconnect, Cloud VPN. Public Peering (Google public IPs only, no SLA): Direct Peering, Carrier Peering.
Cloud VPN
Regional. IPsec VPN. Low-volume, persistent static connections between gateways. VPN Gateways must have static IP. Encrypted link to VPC into one subnet. Supports Static and Dynamic routing. 99.9% SLA. Pay per tunnel-hour.
Dedicated Interconnect
Regional / Multi-Regional. Direct physical link between VPC and on-prem for high-volume connections. VLAN attachment is private but NOT encrypted — layer your own encryption. Redundant connections achieve 99.99% SLA; without redundancy: 99.9%. Pay per 10Gbps link plus per VLAN attachment.
Cloud Router
Regional. Dynamic BGP routing for hybrid networks. Works with Cloud VPN and Dedicated Interconnect. Automatically learns subnets and announces to on-prem. Free to set up; pay for VPC egress.
CDN Interconnect
Regional / Multi-Regional. Direct, low-latency connectivity to external CDN providers (Akamai, Cloudflare, Fastly) with cheaper egress. Free to enable; pay less for configured egress.

Big Data & IoT

IoT Core
Global. Fully Managed. Connect, manage, and ingest data from devices globally via MQTT or HTTPS. CA-signed certs verify device ownership. Pay per MB of data exchanged.
Cloud Pub/Sub
Global. Infinitely scalable. At-least-once messaging for ingestion and decoupling. Pay for data volume (min 1KB per publish/push/pull request). Push mode: delivers to HTTPS endpoints, deletes on HTTP success. Pull mode: delivers to requesting clients, supports batching and long-polling.
Cloud Dataprep
Global. Visually explore, clean, and prep data for analysis without servers. Ad-hoc ETL for business analysts. Managed version of Trifacta Wrangler. Sources: GCS, BigQuery, File Upload (CSV/JSON/relational).
Cloud Dataproc
Zonal. Batch MapReduce via managed Spark & Hadoop clusters. Scales by adding/removing nodes while jobs run. Integrates with GCS, BigQuery, Bigtable, Stackdriver. Use to migrate existing Spark/Hadoop to GCP; use Dataflow for new pipelines.
Cloud Dataflow
Zonal. Fully Managed Apache Beam. Smartly autoscaled, dynamically redistributes lagging work mid-job. Batch or Stream MapReduce-like processing. Integrates with Pub/Sub, Datastore, BigQuery, Bigtable, Cloud ML, Stackdriver.
Cloud Datalab
Regional. Interactive data exploration, analysis, visualisation, and ML. Uses Jupyter Notebook.
Cloud Data Studio
Global. Big Data visualisation tool for dashboards and reporting. Similar to AWS QuickSight and Tableau.

Operations & Management

Stackdriver
Global. Family of services for monitoring, logging, and diagnosing apps on GCP and AWS.
Stackdriver Monitoring
Provides visibility into performance, uptime, and overall health of cloud apps. Built-in custom metrics, dashboards, global uptime monitoring, and alerts. Premium supports AWS. Alerts via email and GCP Mobile App (Premium: SMS, Slack, SNS, HipChat, webhook).
Stackdriver Logging
Store, search, analyse, and alert on log data and events. Based on Fluentd. Create real-time metrics from logs. Export to BigQuery for advanced analytics or to GCS before expiry.
Stackdriver Reporting
Counts, analyses, aggregates, and tracks crashes in a centralised interface. Alerts on new errors. Supports: Java, Python, JavaScript, Ruby, C#, PHP, Go.
Stackdriver Trace
Tracks and displays call trees and timings across distributed systems. Automatically captures traces from App Engine. Zipkin collector support.
Stackdriver Debugger
Grabs program state (callstack, vars, expressions) in live deployments. Source view supports: Cloud Source Repository, GitHub, Bitbucket, Local/Upload. Free to use.
Cloud Deployment Manager
Global. Similar to Terraform and CloudFormation. Create and manage resources via declarative templates written in YAML, Python, or Jinja2. Supports input/output parameters and deployment preview.
Cloud Billing API
Global. Programmatically manage billing for GCP projects and get GCP pricing.

Development & APIs

Cloud Endpoints
Global. Handles auth, monitoring, logging, and API keys for APIs backed by GCP. Based on NGINX; runs as an ESP (Extensible Service Proxy) container hooking into Cloud Load Balancer. Uses JWT. Integrates with Firebase, Auth0, and Google Auth. Pay per API call.
Cloud Shell
Pre-configured Google SDK Linux instance. Automatic auth based on GCP Console login. Accessible via any web browser. All client libs pre-installed. 5GB persistent storage. For direct/interactive use only.
gcloud CLI
Manage GCP resources. Format: gcloud [GROUP] [GROUP] [COMMAND] --arguments. Example: gcloud compute instances create instance-1 --zone us-central1-a. gcloud alpha: not ready for production. gcloud beta: completed feature being tested for production.
