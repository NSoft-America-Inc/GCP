# GitHub Issue Handler

작업 결과물을 GitHub 이슈와 동기화하고 관리한다.

---

## 1. 이슈 상태 파악

작업 전 아래 정보를 먼저 확인한다.

```bash
gh issue view {issue_number}
```

확인 항목: 제목, 완료 기준, 기존 코멘트 히스토리.

---

## 2. 작업 완료 보고 (코멘트)

`tasks/reports/`의 핵심 내용을 요약하여 이슈에 코멘트를 남긴다.

```markdown
### 작업 완료 보고

**요약:**
- {작업 목적 및 결과 1문장}

**산출물:**
- 커밋: `{hash}` ({메시지})
- 리포트: `tasks/reports/YYYYMMDD-{주제}.md`

**검증 결과:**
| 항목 | 결과 |
|---|---|
| {테스트 항목 1} | ✅ PASS |
| 정적 분석 | ✅ CLEAN |

**완료 기준 검증:**
- [x] {이슈 본문의 완료 기준 1}
- [x] {이슈 본문의 완료 기준 2}
```

---

## 3. 이슈 종료 절차

1. **상태 체크**: 완료 코멘트가 작성됐는지 확인한다.
2. **사용자 승인**: "완료 기준을 모두 충족했습니다. 이슈를 Close 할까요?" 라고 묻는다.
3. **실행**: 승인 시에만 `gh issue close {number}`를 실행한다.

---

## 준수 사항

- 이슈 번호를 모를 경우 `gh issue list --state open`으로 먼저 확인한다.
- **자동 클로즈 절대 금지** — 반드시 사용자 확인 후 실행한다.
- 코멘트 작성 전 `tasks/reports/` 경로를 검증한다.
