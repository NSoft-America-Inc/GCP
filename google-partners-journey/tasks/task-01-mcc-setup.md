# Task 01: Google Cloud Partner Network 포털 등록

## 📌 목표
NSoft America를 Google Cloud Partner Network에 공식 등록하여 **Member 등급**으로 여정을 시작합니다.
파트너 포털 등록은 무료이며, 등록 즉시 Member 등급이 부여됩니다.

> ⚠️ 이 Task는 Google Ads MCC와 무관합니다. 별도 포털(partners.cloud.google.com)에서 진행합니다.

---

## 📋 체크리스트
- [ ] 등록에 사용할 회사 Google 계정 준비 (Google Workspace 계정 권장)
- [ ] 파트너 포털 등록 페이지 접속
- [ ] 회사 이메일 입력 및 이메일 인증
- [ ] 회사 프로필 입력 (상호명, 주소, 웹사이트)
- [ ] 파트너 유형 선택 → **Services Partner**
- [ ] 이용약관 동의
- [ ] Member 등급 진입 확인

---

## 📖 실행 가이드

### 1. 계정 준비
등록에 사용할 Google 계정을 준비합니다.
- **권장**: Google Workspace 도메인 계정 (예: admin@nsoftamerica.com)
- 개인 Gmail 계정도 가능하나, 추후 팀 관리를 위해 회사 계정을 사용하는 것을 권장합니다.

### 2. 파트너 포털 접속
[https://partners.cloud.google.com/enrollment/enter-email](https://partners.cloud.google.com/enrollment/enter-email) 에 접속합니다.

### 3. 이메일 입력 및 인증
- 회사 이메일을 입력하고 인증 이메일을 수신합니다.
- 기존 GCP 계정이 연동될 수 있으니 확인합니다.

### 4. 회사 프로필 입력
| 항목 | 입력값 |
| :--- | :--- |
| **회사명** | NSoft America, Inc. |
| **웹사이트** | https://nsoftamerica.com (또는 실제 URL) |
| **주소** | 미국 법인 주소 |
| **직원 수** | 실제 인원 |

### 5. 파트너 유형 선택
- **Services Partner** 선택 → GCP 인프라 구축·운영·관리를 제공하는 사업자
- (Technology Partner는 자체 SaaS 제품을 GCP 위에 구축하는 경우)

### 6. 완료 확인
- 등록 완료 후 파트너 포털 대시보드에 접속됩니다.
- **Member** 등급으로 표시되는지 확인합니다.
- 대시보드에서 인증 현황, 소비 실적, 고객 사례 섹션을 확인합니다.
