# Task 01: Google Ads 관리자 계정(MCC) 생성

## 📌 목표
NSoft America의 모든 광고 계정을 통합 관리하고, Google Partners 프로그램에 등록하기 위한 기초 인프라인 **관리자 계정(MCC)**을 생성합니다.

## 📋 체크리스트
- [ ] 관리자용 구글 계정(이메일) 준비
- [ ] Google Ads MCC 생성 페이지 접속
- [ ] 계정 이름 설정 (예: NSoft America Manager)
- [ ] 관리 방식 선택 ('내 계정 관리' 또는 '다른 사람의 계정 관리')
- [ ] 국가, 시간대, 통화 설정 (대한민국, 서울, KRW 또는 USD)

## 📖 실행 가이드

### 1. 계정 준비
MCC를 소유할 구글 계정이 필요합니다. 개인 계정보다는 회사 공용 관리 계정(예: ads-admin@nsoft.com)을 권장합니다.

### 2. MCC 생성 페이지 접속
[Google Ads 관리자 계정 생성 페이지](https://ads.google.com/home/tools/manager-accounts/)에 접속하여 '관리자 계정 만들기' 버튼을 클릭합니다.

### 3. 기본 정보 입력
- **계정 표시 이름**: `NSoft America - Admin` (자유롭게 설정 가능)
- **계정 사용 목적**: `내 계정 관리` (직접 광고를 운영할 경우) 또는 `다른 사람의 계정 관리` (대행 서비스 제공 시)
- **결제 정보**: 통화는 한번 설정하면 변경이 어려우므로 신중히 선택하세요. (프로젝트 성격에 따라 USD 또는 KRW)

### 4. 완료 후 확인
생성이 완료되면 상단에 **10자리 고객 ID(CID)**가 표시됩니다. 이 ID를 메모해 두세요.

---

MCC 생성이 완료되면 고객 ID를 공유해 주세요. 이어서 **Step 1.2: Google Partners 프로그램 가입**으로 진행합니다.
