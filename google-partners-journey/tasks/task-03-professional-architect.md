# Task 03: Professional Cloud Architect 인증 취득

## 📌 목표
Google Cloud Partner Network Select 등급의 핵심 요건인 **Professional Cloud Architect** 인증을 취득합니다.
이 인증은 GCP 기술 역량의 공식적인 증명이며, 파트너 포털 점수에 가장 높은 비중을 차지합니다.

---

## 📋 체크리스트
- [ ] Cloud Skills Boost 학습 계획 수립 (권장: 2~3개월)
- [ ] 공식 시험 가이드 확인
- [ ] 연습 문제(Practice Exam) 통과
- [ ] 시험 등록 (Webassessor 또는 Kryterion)
- [ ] 시험 응시 (원격 또는 시험 센터)
- [ ] 합격 확인 및 파트너 포털 자동 연동 확인

---

## 📖 학습 로드맵

### Step 1: 기초 다지기 (2~4주)
- [Cloud Skills Boost: Cloud Architecture Learning Path](https://cloudskillsboost.google/paths/12)
- GCP 핵심 서비스 이해: Compute Engine, Cloud SQL, GKE, VPC, Cloud Storage

### Step 2: 실습 위주 학습 (4~6주)
- Qwiklabs 핵심 실습 완료
- 실제 용산 MES 프로젝트 구성 요소와 연계하여 학습
  - MIG + Autoscaling, Cloud SQL HA, Cloud Armor, CI/CD 파이프라인

### Step 3: 시험 준비 (2주)
- 공식 연습 문제: [https://cloud.google.com/certification/practice-exam/cloud-architect](https://cloud.google.com/certification/practice-exam/cloud-architect)
- 케이스 스터디 문서 숙지 (시험에 실제 등장)

### Step 4: 시험 등록 및 응시
- [Webassessor 등록](https://www.webassessor.com/googlecloud)
- 응시 전 파트너 포털 연동 계정과 동일한 Google 계정 사용 확인
