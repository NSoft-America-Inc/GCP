# Task 02: Google Partners 프로그램 공식 등록

## 📌 목표
생성된 관리자 계정(MCC)을 Google Partners 프로그램에 공식 등록하여 파트너 등급 획득을 위한 여정을 공식화합니다.

## 📋 체크리스트
- [ ] MCC 내 'Google 파트너 프로그램' 메뉴 접속
- [ ] 프로그램 이용약관 동의
- [ ] 회사 정보(웹사이트 URL, 주소 등) 등록
- [ ] 가입 완료 확인 및 대시보드 활성화

## 📖 실행 가이드

### 1. 프로그램 메뉴 접속
- Google Ads MCC(`466-235-9797`)에 로그인합니다.
- 왼쪽 메뉴 하단의 **[관리(Admin)]** 아이콘을 클릭합니다.
- 하위 메뉴 중 **[Google 파트너 프로그램]**을 찾아 클릭합니다.

### 2. 가입 프로세스 시작
- 화면에 나타나는 'Google 파트너 프로그램 가입' 버튼을 클릭합니다.
- 서비스 약관을 검토하고 **동의**를 선택합니다.

### 3. 회사 프로필 설정
- **웹사이트**: NSoft America 공식 웹사이트 URL을 입력합니다. (예: `https://nsoftamerica.com`)
- **비즈니스 주소**: 공식 사업장 주소를 입력합니다.
- **이메일 알림**: 파트너 혜택 및 업데이트 정보를 받을 이메일 설정을 확인합니다.

### 4. 등록 완료 및 상태 확인
- 등록이 완료되면 'Google 파트너 등급 현황' 대시보드가 나타납니다.
- 현재 상태가 **'멤버(Member)'** 또는 **'준비 중'**으로 표시되는지 확인합니다.
