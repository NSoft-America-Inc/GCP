# Task 02: 회사 프로필 설정 및 팀 연동

## 📌 목표
파트너 포털에 NSoft America 회사 프로필을 완성하고, 팀원을 연동하여 인증 취득 실적이 파트너 계정에 집계되도록 설정합니다.

---

## 📋 체크리스트
- [ ] 파트너 포털 로그인 (partners.cloud.google.com)
- [ ] 회사 프로필 상세 정보 입력 완료
- [ ] 비즈니스 전문 분야 선택 (Infrastructure, Application Development 등)
- [ ] 팀원 초대 및 포털 계정 연동
- [ ] 팀원 Google 계정 ↔ 파트너 포털 계정 연결 확인

---

## 📖 실행 가이드

### 1. 파트너 포털 로그인
[https://partners.cloud.google.com/u/0/home](https://partners.cloud.google.com/u/0/home) 접속 후 Task 01에서 등록한 계정으로 로그인합니다.

### 2. 회사 프로필 완성
- **Overview**: 회사 소개 (한국 법인 + 미국 법인 배경, GCP 클라우드 서비스 전문)
- **Specialization**: Infrastructure, Application Modernization 선택
- **서비스 지역**: North America (미국), Asia Pacific (한국) 선택

### 3. 팀원 초대
파트너 포털의 **Team** 섹션에서 팀원을 초대합니다.
- 팀원 구글 계정 이메일로 초대 발송
- 팀원이 초대를 수락하면 포털에 연동됩니다.
- **중요**: GCP 인증 취득 시 파트너 포털에 연동된 구글 계정으로 시험에 응시해야 인증이 자동 집계됩니다.

### 4. 인증 연동 확인
- 파트너 포털 > **Certifications** 탭에서 팀원별 인증 현황 확인
- GCP 인증 취득 후 48시간 내 자동 반영됩니다.

---

## 💡 팀원 연동 시 주의사항

| 항목 | 내용 |
| :--- | :--- |
| **시험 응시 계정** | 파트너 포털에 연동된 Google 계정과 동일해야 함 |
| **인증 유효기간** | GCP Professional 인증은 2년 유효, 갱신 필요 |
| **자동 집계** | 시험 합격 후 파트너 포털에 자동 반영 (수동 등록 불필요) |
